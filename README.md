## ⚙️ How I build

**🧪 Evals before features.**
Retrieval evals, voice-latency gates, nightly sweeps and regression gates wired into CI.
Releases block on measured quality, not vibes.

**🤖 Multi-agent orchestration at real scale.**
Dozens of specialized subagents with scoped tools, run under deterministic workflows
rather than model-directed chains.

**🔀 Model-agnostic by design.**
Open-weight and frontier models both run in production. Model choice is a per-workload
engineering decision backed by evals — never a vendor commitment.

**📐 Domain-grounded, not hallucinated.**
Semantic layers and canonical-fact resolution, so a claim about a deal or a covenant
traces to a source — never to a guess.

**🚢 Production discipline.**
16,499 CI workflow runs. Canary deploys, error-budget monitoring, automated error triage.
